# Troubleshooting

The messages below are the ones the tools actually print. Search this page for a few words of
the error.

## Install and tooling

| Message                                                                       | Cause                                                                            | Fix                                                                                                                 |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `ERR_PNPM_UNSUPPORTED_ENGINE ... wanted: {"node":"^24.15.0 \|\| >=26.0.0"}`   | Node.js too old (`engineStrict`)                                                 | Install Node 24 (`.nvmrc`): `nvm install 24 && nvm use`, or `fnm use`                                               |
| `ERR_PNPM_IGNORED_BUILDS ... Ignored build scripts: <pkg>`                    | A new dependency wants to run an install script                                  | Set it to `true` or `false` under `allowBuilds` in `pnpm-workspace.yaml` ([how-to.md](how-to.md#add-a-dependency))  |
| `ERR_PNPM_NO_MATURE_MATCHING_VERSION ... within the minimumReleaseAge cutoff` | The version was published less than seven days ago                               | Wait, or use the previous version; urgent security fix: `minimumReleaseAgeExclude`                                  |
| `High-risk trust downgrade for "<pkg>@<version>" (possible package takeover)` | The version was published with weaker evidence than earlier ones (`trustPolicy`) | Use the previous version and check the package's repository for an incident; `trustPolicyExclude` only after review |
| `ERR_PNPM_OUTDATED_LOCKFILE` (CI, `--frozen-lockfile`)                        | `package.json` changed without updating `pnpm-lock.yaml`                         | Run `pnpm install` locally and commit the lockfile                                                                  |
| `failed to connect to the docker API`                                         | Docker is not running                                                            | Start Docker Desktop (or the Docker daemon)                                                                         |
| Editor shows old Prisma or API types                                          | The TypeScript server cached them                                                | VS Code: "TypeScript: Restart TS Server"                                                                            |

## Database

| Message                                                                              | Cause                                                           | Fix                                                                                                                                     |
| ------------------------------------------------------------------------------------ | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm db:up`: port is already allocated / bind failed on 5432                        | Another PostgreSQL uses the port                                | Root `.env`: `DB_PORT=5442`, and the same port in `DATABASE_URL` in `apps/api/.env`                                                     |
| `DATABASE_URL is not set: copy apps/api/.env.example to apps/api/.env`               | Integration or E2E tests without a configured database          | Create `apps/api/.env` from the example, or set `DATABASE_URL`                                                                          |
| `The seed creates accounts with public passwords: refusing the database at "<host>"` | `pnpm db:seed` against a database on another machine            | Seed local databases only; for a disposable remote one: `pnpm db:seed --allow-remote-database`                                          |
| `Cannot reach PostgreSQL at localhost:5432 (...). Start it with pnpm db:up`          | Integration tests without a database                            | `pnpm db:up`, or point `DATABASE_URL` at a server                                                                                       |
| `Property '<field>' does not exist` on a Prisma model after a pull                   | The Prisma client is older than the schema                      | `pnpm db:migrate` (applies the new migrations and regenerates)                                                                          |
| `Drift detected: Your database schema is not in sync with your migration history`    | The dev database was changed by hand, or a migration was edited | Never edit applied migrations; for a development database with nothing to keep, reset it: `pnpm --filter api exec prisma migrate reset` |
| `P2002` answered as `409 A record with this value already exists`                    | Unique constraint                                               | Expected behavior; validate earlier or handle the 409 in the client                                                                     |

## API at runtime

| Message                                                                                                   | Cause                                                                                                                                  | Fix                                                                                                         |
| --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Environment variable JWT_ACCESS_SECRET is invalid: ...` (or any other) at boot                           | `apps/api/.env` missing or incomplete                                                                                                  | `cp apps/api/.env.example apps/api/.env`, fill the value ([environment.md](environment.md))                 |
| `Environment variable NODE_ENV is invalid` at boot                                                        | `NODE_ENV` has no default, on purpose                                                                                                  | Set it: `development` in `apps/api/.env`, `production` in deployments (the Dockerfile sets it)              |
| `Environment variable JWT_ACCESS_SECRET is invalid: must be at least 64 characters: openssl rand -hex 32` | A short or hand-written secret                                                                                                         | `openssl rand -hex 32`, one value per environment                                                           |
| `Environment variable TRUST_PROXY is invalid: required in production: ...`                                | Production without the proxy setting                                                                                                   | `TRUST_PROXY=1` behind the web image; the real hop count elsewhere ([security.md](security.md#https))       |
| `Environment variable JWT_ACCESS_SECRET_PREVIOUS is invalid: must differ from JWT_ACCESS_SECRET`          | A rotation step with both values equal                                                                                                 | Set the old secret as previous, or remove it ([security.md](security.md#secret-rotation))                   |
| `415 Request bodies must be application/json`                                                             | A form, text or file body                                                                                                              | Send JSON; a file-upload route is exempted explicitly ([api-conventions.md](api-conventions.md#validation)) |
| `401 Missing access token`                                                                                | Route needs `@Auth()` and no bearer token was sent                                                                                     | Call the API through `api` in the web app (it adds the token)                                               |
| `401 Ambiguous session cookies` on refresh                                                                | Outside production (no `__Host-` prefix): two `refresh_token` cookies reach the API, one set for a parent domain by another local site | Delete the extra cookie (browser DevTools → Application → Cookies)                                          |
| `403 Cross-origin request refused`                                                                        | A page on another origin (another site, or a sibling subdomain) made the browser call the API                                          | Same-origin deployment, or add the origin to `CORS_ORIGINS` ([security.md](security.md#csrf-cors-xss))      |
| `429 Too many requests, retry later` while testing                                                        | Rate limit (sign-in: 10 per minute per IP)                                                                                             | Wait for `Retry-After`, or restart the API (counters are in memory)                                         |
| Web dev server: `http proxy error` ... `ECONNREFUSED`                                                     | The API is not running, or `API_PROXY_TARGET` names `localhost` while the API listens on 127.0.0.1                                     | Start the API (`pnpm dev`); use `http://127.0.0.1:<port>` as the target                                     |
| Sign-in page: "You are signed out here, but the server could not be reached to end the session."          | The logout request failed (offline, server down)                                                                                       | "Retry sign-out" once the server is reachable; until then the session may still be valid on the server      |
| `500 An unexpected error occurred`                                                                        | A bug or a dependency failure                                                                                                          | Find the `X-Request-Id` of the response in the API log: the stack is there                                  |

## Optional infrastructure and observability

| Message                                                                                                           | Cause                                                                                                                                                                                                                                          | Fix                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `Environment variable RATE_LIMIT_STORE is invalid: redis requires REDIS_URL` (or `CACHE_STORE`, `REDIS_REQUIRED`) | A Redis-backed feature without a Redis to use                                                                                                                                                                                                  | Set `REDIS_URL`, or the feature back to `memory` ([architecture.md](architecture.md#redis))                                                 |
| `Redis unavailable (redis://...): ... ECONNREFUSED`                                                               | Redis is not running or not reachable                                                                                                                                                                                                          | `docker compose --profile redis up -d`; the app keeps serving in degraded mode meanwhile ([architecture.md](architecture.md#degradation))   |
| `Redis unavailable ...: WRONGPASS invalid username-password pair`                                                 | The password in `REDIS_URL` is not `REDIS_PASSWORD`                                                                                                                                                                                            | Copy the password from the root `.env` into `REDIS_URL`                                                                                     |
| Redis container exits: `REDIS_PASSWORD is empty: set it in the root .env`                                         | No password for the local Redis                                                                                                                                                                                                                | `REDIS_PASSWORD=<output of openssl rand -hex 24>` in the root `.env`                                                                        |
| `Rate limiting falls back to per-instance counters`                                                               | The shared rate limit store lost Redis                                                                                                                                                                                                         | Expected while Redis is down; `Rate limiting uses the shared Redis counters again` follows when it is back                                  |
| Readiness `"status": "degraded"`                                                                                  | An optional Redis is down                                                                                                                                                                                                                      | Fix Redis; traffic keeps flowing. `REDIS_REQUIRED=true` makes it a 503 instead                                                              |
| `Slow query (812 ms): SELECT ...`                                                                                 | A query over `DB_SLOW_QUERY_MS`                                                                                                                                                                                                                | Add the index the plan needs (`EXPLAIN ANALYZE`), or fetch less; raise the threshold only if the query is expected to be slow               |
| `Environment variable SENTRY_DSN is invalid: must be a Sentry DSN`                                                | Not the DSN (the project's key URL), or a typo                                                                                                                                                                                                 | Copy the DSN from the Sentry project settings: `https://<key>@<host>/<project id>`                                                          |
| Web container exits: `Environment variable WEB_SENTRY_DSN is invalid` (or `APP_ENVIRONMENT`, `APP_RELEASE`)       | A runtime setting with characters the web server will not embed                                                                                                                                                                                | Fix the value; it must be an https Sentry DSN ([environment.md](environment.md#web-variables))                                              |
| Browser console: `Refused to connect to https://...ingest...` (CSP)                                               | `WEB_SENTRY_DSN` and the ingest host differ (an unusual DSN)                                                                                                                                                                                   | Use the DSN exactly as Sentry gives it; the CSP origin is derived from it                                                                   |
| No traces or metrics in the backend                                                                               | Telemetry off (`tracing and metrics off` in the boot line), wrong endpoint, or credentials missing                                                                                                                                             | Set `OTEL_EXPORTER_OTLP_ENDPOINT` (base URL, without `/v1/traces`), `OTEL_EXPORTER_OTLP_HEADERS`; check `OTEL_SDK_DISABLED` and the sampler |
| The Redis specs are skipped in `pnpm test:integration`                                                            | No Redis URL configured locally: optional (with one set and Redis down, they fail instead)                                                                                                                                                     | `docker compose --profile redis up -d` and `REDIS_URL` in `apps/api/.env` to run them; CI always does                                       |
| `pnpm sast` runs for many minutes                                                                                 | The first run pulls the Semgrep image; after that it scans a temporary copy of the files git tracks or would add (a few minutes). Much longer: Docker is short of CPU or memory, or large untracked files git does not ignore are being copied | Check Docker Desktop's resources and `git status` for large untracked files; CI takes about two minutes                                     |

## Quality gates

| Message                                                                               | Cause                                                              | Fix                                                                                                                              |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| Test `matches the committed openapi/openapi.json (run pnpm contract when this fails)` | Controllers or schemas changed after the last export               | `pnpm contract`, review and commit both generated files                                                                          |
| `src/api/schema.d.ts does not match openapi/openapi.json`                             | The web types are stale                                            | `pnpm contract`                                                                                                                  |
| `ERROR: Coverage for lines (93.88%) does not meet global threshold (94%)`             | New code lowered coverage below the floor                          | Add tests for the new code (error paths, every service method); see [testing.md](testing.md#coverage)                            |
| `OVER BUDGET  JavaScript, initial: ...` (or another budget's name)                    | The web bundle grew past `performance-budget.json`                 | Lazy-load the route or drop the heavy dependency; raise the budget only in a reviewed pull request                               |
| CI `Scan for known vulnerabilities` fails with a table of CVEs                        | An image contains a package with a fixable HIGH/CRITICAL advisory  | Rebuild (newer base patches), update the base image or the dependency ([security.md](security.md#container-images))              |
| `N vulnerabilities found ... Severity: ... high` from `pnpm security`                 | A dependency has a published advisory                              | Update it; if a dependency pins it, a scoped override ([security.md](security.md#dependency-vulnerabilities))                    |
| `[GITHUB_TOKEN] found GitHub Token` (or another secretlint rule)                      | A secret in a file                                                 | Remove it; if it was real, rotate it                                                                                             |
| `<pkg>@<version> (production): license "<id>" is not allowed` from `pnpm deps:check`  | A dependency's license is outside the policy                       | Pick another package, or a reviewed exception in `scripts/dependency-policy.json` ([security.md](security.md#dependency-policy)) |
| `not resolved from the registry with a sha512 hash` from `pnpm deps:check`            | A dependency from a git repository, a URL or a folder              | Use a registry release ([security.md](security.md#dependency-policy))                                                            |
| CI `Static analysis (Semgrep)` fails with a rule id                                   | A pattern of a known vulnerability, or a weakened security setting | Fix it; a proven false positive: `// nosemgrep: <rule-id> -- reason` ([security.md](security.md#static-analysis))                |
| CI `Lint GitHub workflows` reports a zizmor finding                                   | A workflow change broke a rule of docs/ci-cd.md#workflow-security  | Apply the fix zizmor suggests (permissions, `env:` instead of `${{ }}` in `run:`, a pinned SHA)                                  |
| `Could not start Docker` from `pnpm sast` or `pnpm lint:workflows`                    | Docker is not running                                              | Start Docker; CI runs these checks on every pull request anyway                                                                  |

## Deployment and operations

| Message                                                                                         | Cause                                                                                   | Fix                                                                                                                |
| ----------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `FAIL  runtime configuration: release <a>, expected <b>` from `pnpm smoke`                      | The web image of another build still serves (rollout not finished, or the wrong digest) | Wait for the rollout, check the deployed digest; roll back if it does not converge ([ci-cd.md](ci-cd.md#rollback)) |
| `FAIL  API through the web server: status 502, expected 404`                                    | The web server cannot reach the API                                                     | [incident-response.md](incident-response.md#1-api-down)                                                            |
| `FAIL  probes not public: status 200, expected 404`                                             | The web server's configuration exposes `/api/health/`                                   | Restore the `location` block of `apps/web/nginx/default.conf.template`; probes stay private                        |
| `FAIL  API readiness: status 503, expected 200`                                                 | A hard dependency is down (the message says which)                                      | [incident-response.md](incident-response.md#2-readiness-failing)                                                   |
| `Error: P3009 migrate found failed migrations` from `api-migrate`                               | An earlier migration failed and was not resolved                                        | [database.md](database.md#when-a-migration-fails)                                                                  |
| `pnpm-workspace.yaml: minimumReleaseAge is <n>, the policy requires ...` from `pnpm deps:check` | A supply-chain setting was weakened (also `trustPolicy`, `blockExoticSubdeps`)          | Restore it; for one urgent package use `minimumReleaseAgeExclude` ([security.md](security.md#dependency-policy))   |

## Git hooks

| Message                                                   | Cause                                                        | Fix                                                                                                           |
| --------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| `subject may not be empty`, `type may not be empty`       | Commit message is not a Conventional Commit                  | `git commit -m "feat(api): ..."` ([commits.md](commits.md))                                                   |
| `Refusing to commit environment files`                    | A `.env`, `*.env` or `.envrc` file was staged (`git add -f`) | `git restore --staged <file>`                                                                                 |
| `lint-staged prevented an empty git commit`               | The formatter undid the only change                          | Nothing to commit; check the change                                                                           |
| `pre-push: Direct pushes to "main" are not allowed`       | Pushing to `main`                                            | Push a branch and open a pull request (first push of a new repository: `git push --no-verify -u origin main`) |
| `pre-push: Branch "x" must be <type>/<description>`       | Branch name                                                  | `git branch -m feat/<description>`                                                                            |
| `The command line is too long` (Windows) in a custom hook | Absolute paths overflow the 8191-character limit             | Pass relative paths (the template's hook uses `lint-staged --relative`)                                       |

## End-to-end tests

| Message                                                                 | Cause                                                                               | Fix                                                                |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `Executable doesn't exist at ...` / `Please run ... playwright install` | Browser not installed                                                               | `pnpm exec playwright install chromium`                            |
| `Process from config.webServer was not able to start`                   | No build, database down, or ports 3100/4173 in use                                  | `pnpm build`, `pnpm db:up`, stop the process holding the port      |
| A test passes alone and fails in the suite                              | Tests depend on each other's data                                                   | Make each test create what it needs                                |
| `[WebServer] ... Command failed with exit code 1` after the summary     | Playwright stops the servers when the run ends (Windows reports the killed process) | Nothing: the summary (`N passed`) and the exit code are the result |
